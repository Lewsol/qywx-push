API概述

企业微信通知服务提供了简单易用的HTTP API，用于向企业微信应用发送消息通知。通过配置您的企业微信应用信息，系统会生成一个唯一的API地址，您可以通过该地址发送消息。

使用前，您需要先在首页创建配置并获取唯一的API地址。

认证与安全

系统分离三类权限：管理员 Token 用于配置管理，通知 Token 仅用于发送消息，稳定配置 Code 用于管理员定位配置和企业微信回调 URL。

  • 所有配置管理请求使用 Authorization: Bearer <ADMIN_TOKEN>。
  • POST /api/notify/{notify_token} 和企业微信 callback 不需要管理员 Token。
  • 通知 Token 不能查询或修改配置；配置 Code 不能再作为新配置的通知 Token。
  • 回调 Token 使用 AES-256-GCM 加密存储，配置查询只返回是否已配置，不返回明文。
首页只在当前页面 JavaScript 内存中保存管理员 Token，不会写入浏览器存储、Cookie 或 URL；刷新页面后必须重新输入。

发送消息API

请求地址

POST /api/notify/{notify_token}

其中 {notify_token} 来自配置创建结果中的 apiUrl；它仅具备发送权限并可由管理员轮换。

请求头

Content-Type: application/json

请求参数

参数名 类型 必填 说明
title String 否 消息标题，可选。如果提供，将作为消息的第一行显示，并会加粗处理。
content String 是 消息内容，必填。支持简单的markdown格式，如加粗、链接等。

请求示例

curl -X POST "http://your-server.com/api/notify/your-notify-token-here" \
-H "Content-Type: application/json" \
-d '{
  "title": "服务器告警",
  "content": "CPU使用率超过90%，请及时处理！\n\n**详细信息**：\n- 服务器：web-server-01\n- 时间：2023-09-15 14:30:45\n- 当前负载：95%"
}'

返回示例

{
  "message": "发送成功",
  "response": {
    "errcode": 0,
    "errmsg": "ok",
    "msgid": "MSGID1234567890"
  }
}

错误码说明

HTTP状态码 说明
200 请求成功
400 参数错误，如缺少必填参数
404 通知 Token 无效或已轮换
500 服务器内部错误或企业微信API调用失败

配置管理API

以下端点都必须携带管理员认证请求头：

Authorization: Bearer <ADMIN_TOKEN>
  • POST /api/validate
  • POST /api/generate-callback
  • POST /api/complete-config
  • POST /api/configure
  • GET /api/configuration/{code}
  • PUT /api/configuration/{code}
  • POST /api/configuration/{code}/rotate-notify-token

未认证或凭证错误统一返回 HTTP 401。重复调用配置创建接口返回 HTTP 409，且不会返回已有 code 或通知 Token。

查询与更新回调 Token

GET /api/configuration/{code} 不返回 callback_token，仅返回 callback_token_configured 布尔状态。调用 PUT /api/configuration/{code} 时，省略 callback_token 或传空字符串会保留原值；只有传入非空新值才会替换，接口不会回显新旧 Token。

轮换通知 Token

curl -X POST "http://your-server.com/api/configuration/stable-code/rotate-notify-token" \
-H "Authorization: Bearer your-admin-token"

成功响应包含新的 apiUrl。旧通知 URL 立即失效，稳定 code 和企业微信 callback URL 不变。

从旧版本升级时，已有记录会自动以原 code 初始化通知 Token，并在写锁事务中把旧回调 Token 明文迁移为随机 IV 的 GCM 密文和 HMAC 查找摘要，验证成功后清空旧明文。稳定通知 URL 与 callback URL 保持兼容；迁移失败会整体回滚。

集成示例

Shell脚本示例

#!/bin/bash

# 监控服务器CPU使用率并发送告警
CPU_USAGE=$(top -bn1 | grep "Cpu(s)" | awk '{print $2 + $4}')
THRESHOLD=90

if (( $(echo "$CPU_USAGE > $THRESHOLD" | bc -l) )); then
  curl -X POST "http://your-server.com/api/notify/your-notify-token-here" \
  -H "Content-Type: application/json" \
  -d "{
    \"title\": \"CPU告警\",
    \"content\": \"服务器CPU使用率: ${CPU_USAGE}%，超过阈值${THRESHOLD}%\"
  }"
fi

Python示例

import requests
import json

def send_notification(title, content):
    url = "http://your-server.com/api/notify/your-notify-token-here"
    headers = {"Content-Type": "application/json"}
    data = {
        "title": title,
        "content": content
    }
    
    response = requests.post(url, headers=headers, data=json.dumps(data))
    return response.json()

# 使用示例
result = send_notification(
    "数据库备份完成", 
    "数据库备份已完成\n- 数据库：user_db\n- 备份大小：1.2GB\n- 备份时间：2023-09-15 02:00:00"
)
print(result)

Node.js示例

const axios = require('axios');

async function sendNotification(title, content) {
  try {
    const response = await axios.post('http://your-server.com/api/notify/your-notify-token-here', {
      title,
      content
    }, {
      headers: {
        'Content-Type': 'application/json'
      }
    });
    
    return response.data;
  } catch (error) {
    console.error('发送通知失败:', error.response ? error.response.data : error.message);
    throw error;
  }
}

// 使用示例
sendNotification('部署完成', '项目已成功部署到生产环境\n\n版本: v1.2.3\n部署时间: 2023-09-15 15:30:00')
  .then(result => console.log('通知发送成功:', result))
  .catch(err => console.error('通知发送失败:', err));

常见问题

Q: 如何获取通知地址和配置 Code？

A: 在首页先输入管理员 Token，再完成企业微信配置。返回的 apiUrl 包含独立通知 Token；配置 Code 用于管理查询和稳定 callback URL，两者用途不同。

Q: 消息发送失败怎么办？

A: 请检查以下几点：

  • 通知 URL 中的通知 Token 是否正确、是否已轮换
  • 请求参数格式是否正确
  • 企业微信应用的配置是否有效
  • 网络连接是否正常

Q: 是否支持发送图片或文件？

A: 目前仅支持发送文本消息，不支持图片或文件附件。

Q: 消息内容有长度限制吗？

A: 根据企业微信API的限制，消息内容不应超过2048个字符。
