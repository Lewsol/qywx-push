企业微信消息推送和配置管理接口说明

API 概述

服务提供 HTTPS API，用于创建企业微信配置、管理通知 Token 并发送文本消息。

使用前，请先在首页输入管理员 Token 并完成两步配置。

认证、前端资源与浏览器安全

系统分离三类权限：管理员 Token 用于配置管理，通知 Token 仅用于发送消息，稳定配置 Code 用于管理员定位配置和企业微信回调 URL。

  • 所有配置管理请求使用 Authorization: Bearer <ADMIN_TOKEN>。
  • POST /api/notify/{notify_token} 和企业微信 callback 不需要管理员 Token。
  • 首页只在当前页面内存中保存管理员 Token，刷新页面后必须重新输入。
  • 管理页面和本文档的 CSS、JavaScript 均由本服务自托管，不从 CDN、第三方域名或远程字体服务加载运行时代码。
  • 服务响应使用严格 Content Security Policy，仅允许同源脚本、样式和 API 连接，并禁止对象、页面嵌入、base URL 改写及跨源表单提交。
  • 生产请求必须从第一次请求起使用 https://；明文 POST 不会重定向到业务处理。
不要在日志、工单、截图或前端持久化存储中暴露管理员 Token、配置 Code、通知 Token 或企业微信密钥。

发送消息 API

请求地址

POST /api/notify/{notify_token}

通知 Token 来自创建或轮换结果中的 apiUrl，仅具备发送权限。

请求参数

参数名类型必填说明
titleString否消息标题
contentString是消息内容

请求示例

curl -X POST "https://notify.example.com/api/notify/your-notify-token" \
-H "Content-Type: application/json" \
-d '{
  "title": "服务器告警",
  "content": "CPU 使用率超过 90%"
}'

成功响应示例

{
  "message": "发送成功",
  "response": {
    "errcode": 0,
    "errmsg": "ok"
  }
}
HTTP 状态码说明
200请求成功
400参数错误
404通知 Token 无效或已轮换
426请求使用明文 HTTP
500服务或企业微信 API 调用失败

配置管理 API

以下端点必须携带管理员认证请求头：

Authorization: Bearer <ADMIN_TOKEN>
  • POST /api/validate
  • POST /api/generate-callback
  • POST /api/complete-config
  • POST /api/configure
  • GET /api/configuration/{code}
  • PUT /api/configuration/{code}
  • POST /api/configuration/{code}/rotate-notify-token

未认证请求返回 HTTP 401。重复创建返回 HTTP 409，不会返回已有配置 Code 或通知 Token。

回调 Token

GET /api/configuration/{code} 仅返回 callback_token_configured 状态，不返回回调 Token 明文。更新时省略或留空会保留原值。

轮换通知 Token

curl -X POST "https://notify.example.com/api/configuration/stable-code/rotate-notify-token" \
-H "Authorization: Bearer your-admin-token"

成功响应包含新的 apiUrl。旧通知 URL 立即失效，稳定 Code 和 callback URL 不变。

从旧版本升级时，系统会自动为全部历史配置生成新通知 Token，使曾出现在旧日志中的 Code 不再能发送消息。恢复公网流量前，请用管理员认证和原稳定 Code 查询每项配置的新 apiUrl，并更新所有调用方。

常见问题

如何获得通知地址？

在首页完成回调 URL 生成、企业微信白名单配置、成员验证和配置完善，返回的 apiUrl 即通知地址。

如何轮换泄漏的通知 Token？

管理员在首页查询稳定配置 Code 后点击“轮换通知 Token”，并立即更新所有调用方。

支持图片或文件吗？

当前仅支持文本消息。
